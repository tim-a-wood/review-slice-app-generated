# Review Slice Initial Beta

This is the initial beta release of Review Slice, a local-first Windows desktop application for structured, source-linked technical reviews.

## Highlights

- Import Markdown, text, searchable PDF, Word DOCX, CSV, JSON, XML, diff, and patch files, or import a source-code directory.
- Parse searchable PDFs with PDF.js and provide a clear OCR recovery path for image-only documents.
- Preserve reviewable Word document structure, including headings, paragraphs, lists, and tables, with Mammoth.
- Review stable source slices and track accepted, skipped, questioned, and finding-linked decisions.
- Compare revisions while retaining decisions only for unchanged or equivalently relocated content.
- Track source-linked findings through their lifecycle and export a complete review evidence package.
- Keep review content and state on the local computer without requiring network access.

## Download and run

Download `Review-Slice-1.0.0-beta.1-x64.zip`, extract it to a local directory on Windows 11, keep all files together, and run `Review Slice.exe`.

This portable beta is currently unsigned, so Windows may show a security warning on first launch.
